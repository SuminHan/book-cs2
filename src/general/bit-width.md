# 32비트 vs 64비트

"32비트"와 "64비트"가 실제로 무엇을 의미하는지 짧게 애니메이션으로 설명한다:
레지스터 폭, 고정된 비트 수가 표현 가능한 값의 개수를 어떻게 제한하는지,
그리고 그게 그대로 최대 주소 지정 가능 메모리(32비트는 정확히 4GB, 64비트는
약 16EB)로 이어지는 과정. 마지막으로 실행 중인 프로세스의 Code/Data/Heap/Stack
영역이 어떻게 주소를 갖는지, 함수 호출 과정에서 `RIP`/`RSP`/`RBP` 레지스터가
그걸 어떻게 실시간으로 추적하는지까지 다룬다.
