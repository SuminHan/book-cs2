# Lists / Strings

## 1.1. Key Concepts

- List를 생성하는 또 다른 방법: `.append(·)`로 빈 리스트 `[]`에 하나씩 추가하기
- Slicing 연산자: `[ : ]`, `[::2]`(건너뛰기), `[::-1]`(뒤집기)
- List 비교(`==`) / 연결(`+`) / 포함관계(`in`, `not in`) 연산자
- List용 built-in 함수: `sum()`, `max()`, `min()`, `sort()`
- String: `s[i] == c`로 문자 비교, `+`로 새 문자열 이어붙이기(string은 immutable이라
  직접 수정 불가 — 항상 새 문자열을 만들어야 함), 사전순 비교 연산자 `<`

## 1.2. Problem Set

### 필수 문제

**1. `deleteThree(L)`** — 리스트 `L`에서 3을 모두 제거한 리스트를 반환.

```python
def deleteThree(L):
    M = []
    for i in range(len(L)):
        if L[i] != 3:
            M.append(L[i])
    return M

print(deleteThree([2,5,7,3,2,8,3,3]))  # [2,5,7,2,8]
print(deleteThree([2,3,7,3,2,8,3,3]))  # [2,7,2,8]
print(deleteThree([3,3,7,3,2,8,3,3]))  # [7,2,8]
```
> 새 리스트를 만들 땐 `[]`로 초기화한 후 `M.append(·)`로 하나씩 붙여나가면 된다.

**2. `delete(L, e)`** — 리스트 `L`에서 정수 `e`를 모두 제거한 리스트를 반환. (1번과
같은 패턴, 조건만 `e`로 일반화)

**3. `kthSmallest(L, k)`** — 정수 리스트 `L`에서 `k`번째로 작은 값을 반환
(`1 ≤ k ≤ len(L)`).
> `L.sort()`를 쓰면 `L` 자체가 정렬되고 반환값은 `None`이라는 점에 유의.
> `k`번째로 작은 원소는 정렬 후 `L[k]`가 아니라 `L[k-1]`.

**4. `same(L1, L2)`** — 두 리스트가 (순서 상관없이) 같은 원소를 같은 개수만큼
가지면 `True`.
> `L1 == L2`는 순서까지 완전히 같아야 `True`. 정렬 후 비교하면 순서를 무시할 수
> 있다.

**5. `makeSet(L)`** — 리스트 `L`의 원소를 중복 없이 정확히 하나씩만 포함한, 정렬된
리스트를 반환.
> 1, 2번과 유사한 형태 — 지금까지 만든 `M`에 아직 없는 원소일 때만 `append`.
> `x in L` / `x not in L`로 포함 여부 확인.

**6. `sortId(L)`** — `ID`와 이름이 번갈아 나오는 문자열 리스트 `L`을, 학생 ID
기준으로 정렬해서 반환.
> `ID = L[::2]`로 짝수 인덱스만 뽑아낼 수 있다.
> `y = L.index(x)`는 `L`에서 `x`가 처음 등장하는 인덱스(없으면 에러).

**7. `countA(s)`** — 문자열 `s`에서 `"A"`의 개수를 반환.

```python
def countA(s):
    counter = 0
    for i in range(len(s)):
        if s[i] == "A":
            counter += 1
    return counter

print(countA("AbAA"))          # 3
print(countA("bcdAAAdfAA"))    # 5
print(countA("abc"))           # 0
```

**8. `countChar(s, c)`** — 문자열 `s`에서 문자 `c`(길이 1인 문자열)의 개수를 반환.
(7번의 일반화)

**9. `reverse(s)`** — 문자열 `s`를 뒤집은 문자열을 반환.
> `""`로 초기화한 뒤 `+`로 한 글자씩 이어붙이는 패턴: `r = r + ??`. `s`의 뒤쪽
> 문자부터 `r`에 붙여나가면 된다.

**10. `delete(s, c)`** — 문자열 `s`에서 문자 `c`를 모두 제거한 문자열을 반환.
> 9번과 비슷한 형태로, 앞에서부터 `r`에 붙이되 `s[i] != c`일 때만 붙이면 된다.

**11. `replace(s, c, to)`** — 문자열 `s`에서 문자 `c`를 전부 `to`로 교체한 문자열을
반환.
> `s[i] == c`일 때는 `s[i]` 대신 `to`를, 아니면 `s[i]`를 그대로 붙인다.

**12. `firstStr(s1, s2, s3)`** — 세 문자열 중 사전순으로 가장 앞서는 문자열을
반환.
> 문자열 비교 연산자 `<`는 사전순 비교. 예: `"abcde" < "acbde"`는 `True`.

### Optional Problems

*필수 문제와 달리 제출/검사 대상은 아니지만 도움이 되므로 시간이 남으면
시도해볼 것을 권장 (대부분 기출문제).*

**13. `factorize(n)`** — 2 이상의 정수 `n`의 소인수를 오름차순으로 정렬한 리스트를
반환. 예: `factorize(504)` → `[2, 3, 7]` (504 = 2³·3²·7).

**14. `fraction(numer, denom)`** — 두 양의 정수 `numer`, `denom`이 주어질 때, 유리수
`numer/denom`의 연분수(continued fraction) 표현 `[a1, a2, ..., an]`을 반환.
예를 들어 `numer=415, denom=93`이면 `[4, 2, 6, 7]`을 반환한다.

**15.** 함수 f(n)을 "n의 각 자릿수를 제곱해서 더한 값"으로 정의할 때, 주어진 정수
`n` (2 ≤ n ≤ 10억)에 대해 f를 k번 반복 적용한 값이 1이 되는 최소의 양의 정수
`k`를 반환하는 함수 `composition(n)`을 작성 (그런 `k`가 없으면 `None`). 예:
`n=19`이면 `f(19)=82, f(82)=68, f(68)=100, f(100)=1`이므로 `k=4`.

**16.** 키가 정렬된 n명의 학생을 인접한 k개 조로 나눌 때, 각 조의 비용(키의 합 +
그 조 내 키의 최댓값−최솟값)의 총합을 최소화하는 `minCost(heights, k)`를 작성.
예: `heights=[1,3,5,6,10], k=3`이면 최소 비용은 28.
