# Loops

2016년, 국제탐사보도언론인협회(ICIJ)는 파나마의 로펌 모색 폰세카에서
유출된 문서 1,150만 건, 총 2.6테라바이트를 넘겨받았다. 사람이 한 장씩
읽는다면 평생이 걸릴 분량이었다.

기자 수백 명이 협업한 끝에 한 일은, 결국 "파일을 열어서 그 안의 모든
줄(또는 단어)을 훑으며, 원하는 조건을 만족하는 것이 있는지 확인하는"
단순한 작업의 반복이었다 — 특정 이름이 등장하는 문서가 있는가(for
some), 조건을 만족하는 문서가 몇 건인가(counter). 이번 주에 배우는
패턴 그대로다.

## 파일을 코드로 다루기

```python
words = open("input.txt", "r").read().split()
```

이 한 줄이 하는 일은 "파일을 열고, 전체 내용을 읽고, 단어 단위로
쪼개기"다. 사람이 눈으로 1,150만 건을 읽을 수는 없어도, 컴퓨터는 이
한 줄을 기반으로 초당 수만 건을 검사할 수 있다.

## 오늘 배우는 것과의 연결

파나마 페이퍼스 보도는 2016년 아이슬란드 총리 사임을 비롯해 여러 나라의
탈세 수사로 이어졌다.[^panama] 그 시작은 별다를 것 없는 "파일 열기 →
한 줄씩 훑기 → 조건 확인하기"였다.

[^panama]: ICIJ, [*The Panama Papers*](https://www.icij.org/investigations/panama-papers/)
    (2016).

1,150만 건이든 똑같이 적용된다 — 다른 건 오직 컴퓨터가 대신 훑어준다는
사실뿐이다.**
