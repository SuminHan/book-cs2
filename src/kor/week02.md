# Lists / Strings


- List를 생성하는 또 다른 방법: `.append(·)`로 빈 리스트 `[]`에 하나씩 추가하기
- Slicing 연산자: `[ : ]`, `[::2]`(건너뛰기), `[::-1]`(뒤집기)
- List 비교(`==`) / 연결(`+`) / 포함관계(`in`, `not in`) 연산자
- List용 built-in 함수: `sum()`, `max()`, `min()`, `sort()`
- String: `s[i] == c`로 문자 비교, `+`로 새 문자열 이어붙이기(string은 immutable이라
  직접 수정 불가 — 항상 새 문자열을 만들어야 함), 사전순 비교 연산자 `<`
