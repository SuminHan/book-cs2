# L01: CS1 리뷰

## 이번 주 주제

- **함수 (Functions)**
  - parameters/arguments
  - return statements
- **조건문 (Conditionals)**
  - boolean expressions
  - if-else statements
  - nested/chained conditionals
- **반복문 (Loops)**
  - `for` loops with `range(·)`
  - `while` loops
- **리스트 (Lists)**
  - creating a list
  - accessing a list element
- **반복 패턴 (Loop Patterns)**
  - min/max, counter, quantifier ("for all"/"for some")

내용은 싣지 않는다. 이 주차의 진단용 pretest·답안지는 별도로 관리되며 여기에
